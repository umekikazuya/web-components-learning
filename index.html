Step-by-step curriculum

Web Components を体系的に学ぶ教材

フロントエンド経験者向けに、標準 API だけで UI コンポーネントを作る流れを `Custom Elements` から `ElementInternals` まで順番に学べる教材です。

カリキュラムを開く README を読む

この教材で扱うこと

各ステップは「学習目標」「ライブデモ」「ソース」「確認ポイント」で構成しています。

Custom Elements

独自要素の定義、ライフサイクル、属性監視から始めます。

Shadow DOM / Slot

スタイルのカプセル化と構造の再利用を、実例で確認します。

実務で必要な話題

イベント設計、テーマ変更、アクセシビリティ、フォーム連携まで扱います。

学習の進め方

  1. まずは各ステップを順番に開いて、ライブデモを触る
  2. `demo.js` を読んで API と責務を確認する
  3. 練習課題の変更を試して、挙動の違いを比べる
  4. 次のステップへ進み、ひとつ前の知識を土台に増やしていく

想定読者

HTML / CSS / JavaScript の基礎は理解しており、Web Components をこれから体系的に学びたい人を想定しています。

基本的な DOM 操作やイベント処理は既知とし、各 API がコンポーネント設計でどう役立つかに重点を置いています。
