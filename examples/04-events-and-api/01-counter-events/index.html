Step 5: 状態変化を `CustomEvent` で外へ伝える

コンポーネント内部の変化は、外側が購読できるイベントとして公開すると扱いやすくなります。 必要なら method も足して、宣言的な API と命令的な API を使い分けます。

CustomEvent public method component API

このステップで学ぶこと

  • 内部状態を `detail` 付きのイベントで外へ渡す方法
  • `bubbles` と `composed` を設定して Shadow DOM の外でも受け取れるようにすること
  • 必要最小限の method を併設して操作しやすくすること
