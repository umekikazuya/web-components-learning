Topic-first sandbox

Web Components Sandbox

基礎から始めつつ、`ElementInternals`、`adoptedStyleSheets`、Declarative Shadow DOM、`dialog`、`popover` のような新しめの標準 API まで広めに扱う構成です。

Step-by-step route

最初はこの順番で進めるのがおすすめです

  1. `03 Custom Elements` で独自要素の基本を掴む
  2. `01 Shadow DOM` でカプセル化と template / slot を比べる
  3. `04 Accessibility` で意味・状態・関係性を整理する
  4. `02 Styling` で component styling の選択肢を整理する

ここまで終わったら、`05` 以降の発展 track に進むと理解がつながりやすくなります。
