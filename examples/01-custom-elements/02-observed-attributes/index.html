Step 2: Attributes / Properties をそろえる

ここでは `observedAttributes` と property setter を使って、コンポーネントの公開 API を揃えます。 HTML からも JavaScript からも同じ状態を操作できるようにするのが狙いです。

observedAttributes attributeChangedCallback property setter

このステップで学ぶこと

  • 属性の変化に応じて自動再描画する方法
  • property と attribute の責務をそろえる考え方
  • コンポーネントの外側から見た API を設計する視点

確認ポイント

  • 外側から見た API が 2 系統に分かれないよう、property は attribute に寄せると扱いやすくなります。
  • 属性変更で再描画するなら、描画の入口は 1 つにまとめるのが安全です。
