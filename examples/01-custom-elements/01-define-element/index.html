Step 1: Custom Elements の最小構成

まずは独自タグを 1 つ定義し、`connectedCallback()` で初期描画するところから始めます。 一番小さい形で「ブラウザに新しい要素を教える」と何が起きるかを掴むステップです。

Custom Elements connectedCallback 最小実装

このステップで学ぶこと

  • `customElements.define()` で独自タグを登録する流れ
  • `connectedCallback()` が DOM に接続されたときに呼ばれること
  • 通常の HTML タグと同じように独自要素を配置できること
