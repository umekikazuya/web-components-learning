# Examples sandbox

sandbox は topic-first に整理しています。各 track は小さな差分を 1 ステップずつ確認できる構成です。

## 推奨する見方

1. `01-custom-elements/` で Web Components に入る最初の足場を作る
2. `02-shadow-dom/` でカプセル化と composition を比べる
3. `03-accessibility/` で意味・状態・関係性を扱う
4. `04-styling/` でスタイリング API を横断する
5. `05-forms-and-element-internals/` で form 連携と `ElementInternals` を学ぶ
6. `06-advanced-shadow-dom/` で最新の Shadow DOM API を試す
7. `07-ui-patterns/` で dialog / popover / tabs / menu button を標準 API で組み立てる

## step-by-step で見るコツ

- いきなり好きな track に飛ぶより、まずは `01-custom-elements/` から始める
- 各 track は `01` から順に読み、前の step との差分だけを見る
- 1 つの step を読んだら、「追加された API / 属性 / role は何か」を自分の言葉で説明してみる
- 1 track ごとに 1 つだけ exercise をやると、理解が定着しやすいです

## まず見るべき track

最初の学習ルートとしては次の 4 つがおすすめです。

1. `01-custom-elements/`
2. `02-shadow-dom/`
3. `03-accessibility/`
4. `04-styling/`

ブラウザでは `examples/index.html` を入口にするのが見やすいです。
