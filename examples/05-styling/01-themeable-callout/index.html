Step 6: 外側からテーマ変更しやすいコンポーネントにする

見た目を完全に固定するのではなく、CSS カスタムプロパティを公開しておくと、 利用側はブランドカラーや警告色だけを差し替えられます。

CSS custom properties :host theming

このステップで学ぶこと

  • Shadow DOM の中で CSS カスタムプロパティを使う方法
  • 利用側が変えたい値だけを公開する設計
  • 構造は固定しつつ、見た目の拡張余地を残す考え方

ライブデモ

次のデザインレビューでは、公開 API の命名と CSS 変数の範囲を確認します。

ソースを見る

変更可能な見た目だけを `--callout-*` 変数として定義し、それ以外のレイアウトはコンポーネント側で握っています。

index.html demo.js

確認ポイント

  • スタイルを閉じ込めても、必要なデザイントークンだけは外へ開けます。
  • 変更可能なプロパティ名は API なので、意味が伝わる命名が重要です。
  • 次はアクセシブルなトグル UI で、見た目と操作性を両立させます。
