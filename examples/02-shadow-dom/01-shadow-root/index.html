Step 3: Shadow DOM でカプセル化する

このステップでは、要素内部の DOM と CSS を Shadow Root に閉じ込めます。 外側のスタイルが漏れにくくなると、コンポーネントとしての責務がはっきりします。

attachShadow style isolation internal DOM

このステップで学ぶこと

  • `attachShadow({ mode: "open" })` の基本
  • 外側 CSS と内部 CSS の影響範囲の違い
  • コンポーネント内の構造を内部実装として隠す考え方

確認ポイント

  • 内部 DOM が外へ公開されないので、利用側はタグ API に集中できます。
  • スタイルを閉じ込めても、属性やイベントで外と通信する設計は必要です。
  • 次は `template` と `slot` で構造の再利用に進みます。
