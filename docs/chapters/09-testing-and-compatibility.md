# Chapter 09: Testing and compatibility

## ねらい

新しめの Web Components API を広く扱う教材では、実装例だけでなく testing と compatibility の見方もセットで伝える必要があります。

## この教材での最小ライン

- `npm run check` で inline script と設定ファイルの構文を確認する
- `npm test` で examples と docs の構成・主要 API カバレッジを smoke test する
- `npm run build` で Vite の multi-page build が通ることを確認する

詳細は `docs/testing.md` と `docs/compatibility.md` を参照してください。
